# Project 0 — prove you can run Julia on a compute node

**Due Fri Sep 4 (S06).**

## What you do

1. First read `cluster_basics.pdf` in Content -> HPC Materials.
1. Copy `project0.jl` and `project0.sbatch` to the cluster, both into the same directory.
2. Run `sbatch project0.sbatch` on the cluster
3. Submit the resulting **`project0-<jobid>.out`** file, unedited.

Do not retype, reformat, or clean up the output. Submit the file the job produced.

This is a pass/fail project.
